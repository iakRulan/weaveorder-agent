System design

    
织序是怎么工作的

    

      
多智能体协同

      
Intake 解析硬约束并生成澄清问题；Planner 产出带依赖的 DAG；Critic 预审计划；
      Executor 按层并行调用工具；Verifier 做数值/政策/完整性校验；Replanner 在失败时改写计划；
      Narrator 生成可交付摘要；Memory 沉淀长期偏好。

      
两种运行模式

      
    
        
  • DAG 编排：先规划后执行，适合需要审计、依赖与确定性的任务。
    • 
        
  • 自主 Agent：原生 Function Calling，模型自己决定下一步调用哪个工具。
    • 
      

      
安全与可审计

      
    
        
  • 工具参数按 JSON Schema 校验、纠偏、超时与只读重试。
    • 
        
  • risk ≥ 2 的动作进入审批闸门，自动审批仅用于评测/演示。
    • 
        
  • 所有事件写入 trace.jsonl，报告中的数字可反查工具调用。
    • 
      

      
快捷键

      
⌘/Ctrl + ↵ 运行 · Esc 关闭弹窗（审批除外）
