## 常见坑

- **不要把 API Key 写进代码或提交包**：用 `.env`，提交前 `git grep -i "sk-"` 检查。
- **不要用真实公司/客户数据**：mock 数据足够演示，避免隐私问题。
- **视频不要只录 PPT**：至少 3 分钟是真实运行、真实 Trace、真实失败恢复。
- **技术文档不要写成流水账**：按“问题 → 方案 → 实验 → 结论”组织，突出编排引擎的技术难度。
- **先确认赛题手册是否指定评测方式**：如果官方有统一评测入口，我们的评测集只作为补充，不要本末倒置。
