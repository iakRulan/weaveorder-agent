# 前置准备清单

> 目标：在不耽误我写代码的前提下，把你这边必须由本人完成的事情压到最少。现在只需要做 **3 件事**，其余可以边做边补。

## 现在只做这 3 件

### 1. 拿到官方赛题手册（最重要）

登录兴智杯平台，进入“大模型智能体关键能力技术创新赛”详情页，下载或截图：

- 赛题手册 / 作品要求
- 技术文档模板（如果有）
- 评分细则
- 数据集、模型、平台资源说明
- 作品提交格式与压缩包大小限制

把这些文件放到本目录的 `docs/official/` 下，或直接把内容贴给我。**这一步决定方案要不要调整**——尤其是“是否指定必须用某个模型/平台/评测入口”。公开信息只说了代码实现方案、考察自主规划/工具调用/多步推理，细节要以手册为准。

### 2. 注册书生大模型平台，拿 API Key

- 注册：https://internlm.intern-ai.org.cn/
- 获取 Token：https://internlm.intern-ai.org.cn/api/tokens
- 模型选 `intern-s2`（256K 上下文）
- Base URL：`https://chat.intern-ai.org.cn/api/v1/`
- 免费额度约 9000 万 token/月，限速 30 次/分钟，足够这个项目用

拿到后先不要发在聊天里，直接写进本地的 `.env`：

```bash
cp .env.example .env
# 编辑 .env，把 INTERN_API_KEY=... 填上
```

如果手册要求必须用上海 AI Lab 的指定平台/模型，以手册为准；书生 API 是最省事的起步方式。

### 3. 建一个空 GitHub 仓库

- 仓库名建议：`weaveorder-agent` 或 `xingzhi-weaveorder`
- 先设为 public（提交材料通常需要可访问；如果手册要求私有，再改）
- 把仓库地址给我，我这边按目录结构往里填
- 不要提交 `.env`、API Key、真实公司数据

## 常见坑

- **不要把 API Key 写进代码或提交包**：用 `.env`，提交前 `git grep -i "sk-"` 检查。
- **不要用真实公司/客户数据**：mock 数据足够演示，避免隐私问题。
- **视频不要只录 PPT**：至少 3 分钟是真实运行、真实 Trace、真实失败恢复。
- **技术文档不要写成流水账**：按“问题 → 方案 → 实验 → 结论”组织，突出编排引擎的技术难度。
- **先确认赛题手册是否指定评测方式**：如果官方有统一评测入口，我们的评测集只作为补充，不要本末倒置。
